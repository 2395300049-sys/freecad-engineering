# FreeCAD Skill Evolution V1-V8

| Version | Primary advance |
|---|---|
| V1 | Reconstruct numbered parts from 2D drawings with FreeCAD Python and export FCStd/STEP/STL. |
| V2 | Calibrate against trusted STEP references and support portable reconstruction. |
| V3 | Organize revisioned deliverables and preserve accepted outputs. |
| V4 | Audit assemblies, interference, gears, and conflicting reference assemblies. |
| V5 | Add production engineering: operating conditions, tolerances, strength, manufacturing, BOM, cost, supply, motion, and service. |
| V6 | Route configurable 2D-to-3D, 3D-to-2D, assembly, audit, comparison, and local-software workflows. |
| V7 | Add evidence authority, global-placement recovery, physical occurrence ledgers, STEP ppm validation, GUI/viewport gates, and clean-room delivery. |
| V8 | Add localized marked-correction control, invariant-based B-Rep repair acceptance, explicit release-readiness states, and sanitized public/private repository release. |

V8 retains the V5-V7 engineering gates while making corrections and release claims auditable. Completion means the selected evidence gates pass; it never means only that a file was generated.
